# Biziwe 3D

An open-world 3D action game, built in Unity.

This is the Phase 1 foundation. See [`Docs/PHASE1_PLAN.md`](Docs/PHASE1_PLAN.md)
for the full setup guide and current scope — read that first.

**Note:** this repo currently holds C# scripts and setup docs, not a full
importable Unity project yet. That's intentional — see the plan doc for why,
and exactly what to do once you're on a PC with Unity installed.
